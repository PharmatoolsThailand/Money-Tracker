      👤 ผู้ใช้ปัจจุบัน

      ? —

      ข้อมูล/หมวด/งบประมาณของแต่ละผู้ใช้แยกกัน — เก็บใน Google Sheet คนละไฟล์

      📱 ติดตั้งแอป

      ติดตั้งเป็นแอปบนมือถือ/desktop เพื่อใช้แบบ standalone (มี icon + offline)

      • Chrome / Edge: ไอคอน ⊕ บน address bar หรือเมนู ⋮ → "Install Money Tracker"
      • Safari iOS: ปุ่มแชร์ → "Add to Home Screen"
      • ต้องเปิดผ่าน HTTPS (เช่น GitHub Pages, Netlify) ถึงจะ install ได้

      🔗 Google Apps Script

      📖 วิธี setup ครั้งแรก

      1. เปิด sheets.new สร้าง Google Sheet เปล่า ตั้งชื่อ "Money Tracker"
      2. ที่ Sheet → Extensions → Apps Script
      3. ลบ code เดิม → paste code จากไฟล์ apps-script/Code.gs
      4. กด 💾 Save (Ctrl+S)
      5. กด Deploy → New deployment
      6. Type: Web app
      7. Execute as: Me | Who has access: Anyone
      8. กด Deploy → Authorize (Advanced → Allow)
      9. Copy URL ที่ลงท้ายด้วย /exec → paste ด้านบน
      10. กด ทดสอบ → ✓ → บันทึก

      ⚠ อัพเดท Code.gs ภายหลัง: Deploy → Manage deployments → ดินสอแก้ → New version → Deploy. URL เดิมใช้ได้
